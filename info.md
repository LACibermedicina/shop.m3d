# SHOP.M3D.pro (versão: catalogo)

Uma plataforma de **lojas virtuais organizadas por áreas de interesse e grupos de usuários**. Este repositório contém a versão chamada **catalogo** do projeto **SHOP**, que faz parte do ecossistema **M3D.pro**.

## 🎯 Visão Geral

O **SHOP.M3D.pro (versão: catalogo)** é um aplicativo móvel e web que funciona como uma **rede de indicações baseada em grupos de interesse**, conectando clientes e lojistas de forma vinculativa. Nosso objetivo é facilitar conexões de confiança entre consumidores e vendedores por meio de comunidades temáticas.

### Por Que SHOP.M3D.pro?

- 🤝 **Relacionamento Direto**: Conexão próxima entre clientes e vendedores, baseada em confiança
- 🎯 **Grupos de Interesse**: Organização customizada que facilita o encontro de produtos relevantes
- 🛡️ **Proteção de Privacidade**: Reduz o impacto da publicidade predatória de redes sociais
- 💚 **Saúde Mental**: Cria um ambiente de consumo consciente e respeitoso
- 🔗 **Indicações Vinculativas**: Sistema de recomendações orgânico baseado em comunidades

## 📋 Funcionalidades Principais

### Para Clientes
- 📱 Navegação por grupos de interesse
- 🛍️ Acesso a catálogos de lojistas confiáveis
- 💬 Comunicação direta com vendedores
- ⭐ Sistema de recomendações comunitário
- 🔔 Notificações sobre produtos relevantes

### Para Lojistas
- 🏪 Criar e gerenciar vitrine virtual
- 📊 Acesso a métricas de engajamento
- 💼 Gerenciamento de grupos de interesse
- 📧 Comunicação direta com clientes
- 🎯 Distribuição customizada de produtos

### Para a Comunidade
- 🌐 Rede de confiança descentralizada
- 👥 Grupos temáticos organizados
- 🤲 Indicações autênticas e relevantes
- 📈 Crescimento orgânico sem publicidade predatória

## 🚀 Começando

### Pré-requisitos
- Node.js 18+
- npm ou yarn
- Expo CLI (para desenvolvimento móvel)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/LACibermedicina/catalogo.git
cd catalogo

# Instale as dependências
npm install

# Inicie o aplicativo
npx expo start
```

### Desenvolvimento

O projeto utiliza:
- **Frontend**: Expo + React Native (aplicativo mobile multiplataforma)
- **Arquitetura**: File-based routing com Expo Router

Para iniciar o desenvolvimento:

```bash
# Abra em simulador iOS
npx expo start --ios

# Abra em emulador Android
npx expo start --android

# Abra em navegador web
npx expo start --web
```
